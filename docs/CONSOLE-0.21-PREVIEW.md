# DEKA Console Preview 0.21.0

Три варианта пульта доступны внутри одного приложения через кнопку **«Пульт»**.
Desktop включает обычное окно и режим фона. Android — отдельная проверочная
установка «DEKA Console Preview», пакет `ru.volna.player.consolepreview`.

| Пульт | Управление | Оформление |
| --- | --- | --- |
| Aurora Glass | EQ, Master и FX вращаются по кругу; темп — вертикальный фейдер | Тёмные поверхности, бирюзовые и фиолетовые кольца, объёмные ручки |
| Acid Terminal | EQ и Master — вертикальные фейдеры, FX — линейные полосы | Чёрный и лайм, прямые панели, шкалы и прямоугольные колпачки |
| Editorial Mono | EQ и Master: тянуть вверх/вниз; −/+ для точного шага; FX — полосы с шаговыми кнопками | Светлый корпус, металлические ручки, оранжевые и синие акценты |

Карточка показывает предпросмотр. «Сохранить пульт» запоминает выбор;
«Отмена» и Esc восстанавливают предыдущий. Деки, выбранные треки, CUE,
позиции, эффекты, громкость и настройки звука сохраняются при смене пульта.

## Управление

- На Desktop работают мышь и клавиатура: стрелки — один шаг, Page Up/Down —
  десять шагов, Home/End — границы, 0 — исходное значение. Колесо действует
  только на регулятор с фокусом. Двойной щелчок сбрасывает его значение.
- У точных энкодеров Editorial Shift при перетаскивании уменьшает шаг движения.
- На телефоне используются реальные жесты с захватом пальца; разные органы
  управления поддерживают независимые касания. В небольшом горизонтальном
  окне настройки прокручиваются внутри панели, а Play и CUE остаются у деки.
- В APK эффекты находятся во вкладке **FX** каждой деки. «Треки», «Темп» и
  «EQ» открывают соответствующие панели, не выключая эффекты.
- «Свернуть деки» на Desktop сохраняет список, частоты, транспорт и микшер.
  «Показать деки» возвращает полный пульт. Кнопка «Фон» и Ctrl+Alt+F9
  работают в объединённом Desktop.

## Запуск

Windows: закройте предыдущую Deka через трей → «Выход», распакуйте архив
отдельно и запустите `Deka.exe`. Профиль объединённого Desktop сохраняется.

Android: установите APK на arm64-телефон. Основная Deka и прежняя Preview
не заменяются. Эта Console Preview подписана отдельным временным ключом;
совместимость обновления с другими проверочными APK не заявляется.

## Границы этой версии

Варианты изменяют интерфейс и способы ввода. Раздельные Bluetooth-выходы,
headphone CUE и два независимых потока VK этим выпуском не добавляются.
На Android сохранены Low/High и нейтральная середина из версии 0.18.
На Desktop доступны Low/Mid/High. Файлы для обеих дек выбираются заново
после закрытия приложения; аудиофайлы VK не скачиваются.

Проверки публикуются в GitHub Actions для ветки `feature/deka-console-designs`.
Архивы выпускаются после успешного полного прогона. Браузерная проверка
использует настоящие PCM-сигналы, мышь и CDP touch; контент VK подставлен
тестовым стендом. Windows EXE дополнительно запускается в Windows/WebView2.
Подпись, версия, пакет и включённые модули APK проверяются при сборке.

На физическом телефоне ещё нужно проверить системный выбор файлов, реальный
вход VK, задержку скретча, фон/выключенный экран, звонки и Bluetooth. Проблемные
сеты пользователя и два физических монитора не заменяются тестовыми данными.
