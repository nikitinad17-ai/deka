# DEKA 0.21: состояние разработки

Дата: 8 ноября 2026. Это исходники в разработке, не готовая проверенная сборка.

## Подготовлено

- Aurora Glass: круговые регуляторы EQ/FX/Master и вертикальный темп.
- Acid Terminal: вертикальные фейдеры EQ/Master, линейные FX.
- Editorial Mono: относительное движение вверх/вниз, точные кнопки −/+.
- Общие компоненты для Desktop и Android, сохранение выбора пульта.
- Разное расположение органов управления, адаптация к ориентации телефона.
- Отдельная вкладка FX на каждой Android-деке.
- Сохранены единый Desktop, компактный режим и существующий аудиодвижок.
- Подготовлены браузерные проверки мыши, клавиатуры, мультитача и звука.
- Подготовлен workflow проверок и сборок Windows/Android.

## Фактически выполненные проверки

- `npm test`: 53 из 53 тестов аудиологики, очередей, сетов и обработки PCM прошли.
- Проверки синтаксиса JavaScript, согласованности версий, нативных генераторов
  и отсутствия материалов подписи прошли.
- Новые Python-сценарии компилируются; YAML workflow прочитан парсером.
- `git diff --check`: ошибок нет.
