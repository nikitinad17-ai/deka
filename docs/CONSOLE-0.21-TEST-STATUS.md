# DEKA Console Preview 0.21.0: результаты проверки

Дата: 8 ноября 2026. Подготовлены Windows ZIP и Android APK для пользовательского теста.

Исходники сборок: `0d33904846d1fbd449cf5a0095c0a68801c23551`.
Ветка: `feature/deka-console-designs`, репозиторий `nikitinad17-ai/deka`.
[Итоговый прогон GitHub Actions](https://github.com/nikitinad17-ai/deka/actions/runs/42493603174): **success**, попытка 2.
Основная ветка не изменена; GitHub Release не опубликован.

## Что вошло

- Aurora Glass: круговые ручки EQ/FX/Master и вертикальный фейдер темпа.
- Acid Terminal: вертикальные фейдеры EQ/Master и линейные FX.
- Editorial Mono: относительное движение вверх/вниз и точные кнопки −/+.
- Разные компоновки и реальные способы ввода при одном аудиодвижке.
- Кнопка «Пульт», предпросмотр, сохранение выбора и отмена без перезапуска звука.
- Объединённый Desktop с фоном, запуском в DJ и сворачиванием дек.
- Android: портретная и горизонтальная компоновки, вкладка FX каждой деки.
- Исправлены конфликты касаний после регулировки, расположение EQ B, портретные
  перекрытия заголовков и CUE, пропорции круглых регуляторов.

Регрессии: desktop_appearance, desktop_session, android_dj, android018, browser,
continuous, automix, mp3_transport, dj_sets, desktop_dj, desktop_vinyl.
Проверены скретч, эффекты, CUE, темп, автомикс, смена треков и сохранение одного
декодера при переключении интерфейса. PCM измеряется из настоящего Web Audio;
контент VK и мост в браузерных сценариях заменены явными тестовыми данными.

Нативный прогон выполнялся в Windows Server 2022 с настоящими Explorer и WebView2,
на одном виртуальном мониторе 1024×768, с административным токеном CI. Проверены
слои рабочего стола, иконки, трей, Ctrl+Alt+F9, возврат в окно, отсутствие второго
аудиодвижка в фоне и воспроизведение сета A одновременно с локальным треком B.
Это не испытание физического компьютера с Windows 10/11 или двух мониторов.

Скриншоты всех трёх пультов просмотрены: Desktop полностью и компактно; Android
844×390, 390×844 и панели FX. В финальной версии повторно проверены исправленные
портретные заголовки/CUE и круглые ручки компактного Editorial.

## Наблюдение при повторном прогоне

В первой попытке финального прогона `mp3_transport` один раз достиг лимита
ожидания 5 секунд на первом ускоренном переходе. Причина по сохранённому логу
не установлена. Повторный запуск того же коммита без изменения теста прошёл
15 проверок: 11 последовательных переходов, конец очереди, быструю замену,
устойчивую паузу и отсутствие ошибок JavaScript. Предыдущий полный прогон
`42492695708` также прошёл этот сценарий. Сбой не объявляется исправленным;
при повторении на устройстве нужны отчёт и последовательность действий.

## Следующий этап на устройствах

1. Xiaomi: установка, системный выбор файлов, вход VK, звук при выключенном
   экране, звонках и подключении Bluetooth; удобство жестов в обеих ориентациях.
2. Desktop: проблемные пользовательские сеты, длительное воспроизведение,
   переключения окна/фона и два монитора, если используются.
3. Повторение последовательных переходов MP3 с сохранением отчёта при сбое.

Физический телефон, реальный аккаунт VK и пользовательские проблемные сеты
в этом прогоне не проверены. Раздельные Bluetooth-выходы и headphone CUE
не добавлены. Новые варианты реализованы по выбранным направлениям дизайна;
точное совпадение с прежними демоизображениями не заявляется.
