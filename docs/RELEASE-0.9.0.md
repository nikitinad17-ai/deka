# Дека 0.9.0 — проверочная версия

## Что исправлено

Сбор библиотеки вынесен в отдельные тестируемые модули `library-engine.js` и `library-runtime.js`. Старый цикл после прокрутки снова вызывал `scrollIntoView()` для прежней последней строки и мог отменять шаг. Таймаут выдавался за полный список. Новый сборщик читает каждое окно виртуализированного списка до прокрутки, накапливает стабильные ID и различает подтверждённое количество, наблюдаемый конец страницы и неполный проход.

Частичный результат не удаляет хвост ранее сохранённого списка. Прогресс доступен сразу, есть отмена. Кэш разделён по пользователю и странице/плейлисту. Переход к своей музыке передаёт намерение сбора в URL-фрагменте, не только в origin-зависимом sessionStorage. Отсутствующий трек не заменяется первым попавшимся.

## Горизонтальный DJ

Поворот в горизонтальное положение открывает две вертушки A/B с двумя независимыми прокрутками и поиском. Оба списка используют всю сохранённую библиотеку, а не только текущие строки DOM VK. Отрисовка виртуальная: последний трек доступен, но тысячи кнопок не создаются одновременно. Обновление времени воспроизведения не перестраивает списки и не сбрасывает прокрутку.

У двух локальных файлов независимые аудиоэлементы, EQ, CUE, громкость и равномощный кроссфейдер. Захват штатного `play()` выполняется до установки VK-моста, поэтому локальная дека не принимается за звук VK. **У VK один общий поток**: два списка позволяют выбирать и переключать треки, но два VK-трека одновременно эта архитектура не сводит. Это написано на самом пульте.

Старые плейлисты и `myAll` сохраняются отдельными локальными копиями в выборе источника; старые записи не удаляются. Сеты из VK Видео также доступны в источниках.

## Проверки

- 10 модульных сценариев: 1500 виртуальных треков без пропусков, порядок, дедупликация по ID, сохранение хвоста, неполная загрузка, отмена, смена источника, математика кроссфейдера и повреждённые данные.
- 15 браузерных проверок Chromium: 1000 треков в 12 переиспользуемых DOM-строках с отложенной подгрузкой; достижимость последнего трека; независимость A/B; поиск по всему списку; поворот; отсутствие перекрытия нижним плеером; реальное параллельное воспроизведение двух синтетических WAV и независимая пауза.
- Синтаксис JS, согласованность версий, отсутствие ключей в рабочем дереве, идемпотентность генератора Android service.

Браузерные тесты полностью локальные, без VK-аккаунта. Это **не** подтверждение всех вариантов живой разметки VK. Физический Android и сон конкретного телефона не тестировались. Нативные сборки и подпись APK проверяются отдельно в GitHub Actions.

## Установка Android

Раскрытый ключ больше не извлекается из истории Git. При отсутствии защищённых signing secrets CI выпускает `Deka-Preview.apk` с новым временным ключом и отдельным идентификатором `ru.volna.player.preview`. Он устанавливается рядом со старой Декой, не обновляет и не удаляет её данные; вход в VK выполняется заново. Ключ preview не сохраняется и не публикуется, поэтому будущая preview-сборка может потребовать переустановки только Preview.

Обычный `Deka.apk` собирается только с защищёнными `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEY_ALIAS`, `ANDROID_KEYSTORE_PASSWORD`. Совместимость с установленной 0.8 нельзя заявлять без отдельно подтверждённой подписи/плана её ротации.
