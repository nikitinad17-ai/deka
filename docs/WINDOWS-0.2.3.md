# Дека 2 0.2.3 — ручной режим VK на Windows

Диагностическое исправление возврата из VK в пустой пульт. Полная загрузка живой библиотеки этим выпуском не объявляется исправленной.

Windows начинает каждую страницу с исходного VK. Пульт монтируется только по кнопке «Вернуться в Деку». Нажатие VK скрывает его полностью. Переходы между страницами, вход VK ID, окончание сканирования и изменение размера окна не должны возвращать пульт автоматически.

Отключены автоматическая загрузка/навигация при запуске и возврате в пульт, старый collect-фрагмент и автоматическое переключение широкого окна в DJ. «Открыть VK вручную» и «Список в VK» показывают текущую исходную страницу без угадывания URL. Сбор доступен по явной кнопке только в распознанном личном разделе.

В режиме VK скрытая Дека не переопределяет громкость и не переключает песни своей очередью. Собственные файлы, фейдеры и микшер сохранены в режиме Деки.

«Сведения» открывает техническую сводку без паролей, cookie, токенов, названий треков, ID аккаунта, query/hash и HTML. Идентификатор ru.deka2.player и профиль приложения не меняются. Старое приложение не удалять и данные не очищать.

Проверка пользователем: открыть «Мои треки» в самой странице VK, прокрутить дальше первых песен, включить трек. До этой проверки не нажимать «Вернуться в Деку». При сбое нужен снимок исходной страницы и «Сведений»; пароли и коды не присылать.

Новые регрессионные тесты используют реальные переходы документов Chromium на localhost с синтетическими страницами и локальным звуком. Это не проверка реального VK-аккаунта. Изменения ограничены Windows-bootstrap; в этой задаче нет Android APK. Ветка deka2 и main остаются контрольными до пользовательской проверки этой отдельной ветки.
