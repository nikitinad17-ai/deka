# Deka Desktop 0.19.0 Preview

Один `Deka.exe`: обычный плеер, DJ-пульт A/B и фон под ярлыками Windows.
Основа: Desktop 0.18.0 и Wallpaper 0.1.2 RC3. Это предварительная сборка.

## Сеты прямо на деке

1. Откройте DJ · A/B.
2. В списке «Мои файлы / Мои треки VK / Сеты» выберите «Сеты».
3. Нажмите «＋ Сет», вставьте ссылку VK Видео и нажмите «Добавить».
4. Нажмите «В A» или «В B», затем «Играть» на этой деке.
5. Пауза, позиция, темп, Master и кроссфейдер управляют выбранной декой.

Добавление и загрузка сета не запускают звук. Просмотр списка не останавливает
воспроизведение. Список сетов общий с обычным плеером и сохраняется после выхода.
VK использует один поток: одновременно доступен один сет или трек VK. На другой
деке можно слушать локальный файл. Скретч, Reverse, шесть эффектов и анализ BPM
работают для локальных файлов. Автоматическое сведение 17 секунд относится к
локальным файлам; для сетов не обещается анализ BPM или два потока VK.

## Фон и управление

Выберите монитор и нажмите «Фон». Ctrl + Alt + F9 выводит пульт вперёд и возвращает
его в фон. Esc возвращает обычное окно. В фоне клики остаются у ярлыков Windows.

Перед запуском закройте предыдущие Deka и Wallpaper через трей → «Выход».
Распакуйте Preview в отдельную папку. Приложение использует прежний профиль
основной Deka (`ru.volna.player`), поэтому её настройки и сеты остаются общими
для всех режимов. Старый отдельный профиль Wallpaper (`ru.volna.deka.wallpaper`)
не удаляется и автоматически не объединяется: ссылки, добавленные только туда,
потребуется добавить в общий список. Вход в VK зависит от сохранённой сессии
основной Deka. Локальные аудиофайлы после перезапуска выбираются повторно, как раньше.

## Проверка и ограничения

Архив в workflow создаётся только после успешных проверок логики, браузера,
нативного Windows-кода и готового EXE. Нативный тест использует контролируемое
видео в настоящем WebView2, один монитор и Windows Server 2022.
Windows 10 пользователя, два монитора и его реальный VK-аккаунт требуют ручной
приёмки. Успех стенда не означает подтверждения этих сценариев.

Основные проверки пользователя: сет на A; пауза и перемотка; локальный файл на B;
громкость через кроссфейдер; фон под ярлыками; возврат Ctrl + Alt + F9;
открытие ярлыков и непрерывный звук. При сбое используйте «Сохранить отчёт».
