# DEKA Desktop 0.20.0 Preview

Один Deka.exe: DJ-пульт A/B и режим фона под ярлыками Windows.
Приложение сразу открывается в DJ; отдельного экрана обычного плеера больше нет.

## Деки и компактный вид

«Свернуть деки» скрывает вертушки, эффекты, темп и Reverse. Остаются названия A/B,
воспроизведение, предыдущий/следующий трек, перемотка, эквалайзер каждой деки,
Master, кроссфейдер, SHUF, REP 1, Auto Mix и общий список файлов / VK / сетов.
«Показать деки» возвращает полный пульт. Это только изменение отображения:
аудиодвижок, загруженные треки, CUE, эффекты и текущий переход остаются прежними.
При новом запуске всегда открывается полный DJ; автоматического старта звука нет.

## Три темы

Кнопка «Стиль» открывает Aurora Glass, Acid Terminal и Editorial Mono — оформление
по ранее подготовленным концептам с одинаковым расположением управления.
Выбор карточки даёт предпросмотр. «Сохранить стиль» запоминает тему;
«Отмена» или Esc восстанавливают предыдущую. Тема также применяется в фоне.
Используются статические CSS-поверхности и системные шрифты, без фонового видео.

## Файлы, VK и сеты

Выберите источник в списке. «＋ Файлы» или перетаскивание добавляет локальные файлы.
«В A» / «В B» загружает выбранный трек без запуска. Нажмите Play нужной деки.
Для сетов выберите «Сеты» → «＋ Сет» и вставьте ссылку VK Видео.
Вход, окно VK, загрузка библиотеки, ссылки и экспорт доступны в раскрывающемся
блоке «Аккаунт VK и управление библиотекой» при выборе VK или сетов.

VK использует один поток: одновременно один сет/трек VK и локальный файл на
другой деке. Скретч, Reverse, шесть эффектов и анализ BPM работают для файлов.
Автосведение 17 секунд относится к локальным файлам. Возможности эквалайзера
VK зависят от доступа к аудиопотоку. Два независимых потока VK не заявлены.

## Режим фона

«Фон» размещает изображение пульта под ярлыками. Ctrl + Alt + F9 возвращает
управление и отправляет обратно в фон; «Обычное окно» / Esc возвращает окно.
При открытом выборе стиля Esc сначала отменяет предпросмотр.

Перед запуском закройте старую Deka через трей → «Выход». Распакуйте Preview
отдельно. Профиль ru.volna.player и сохранённые сеты общие с основной Deka;
профиль старого отдельного Wallpaper не объединяется автоматически.
Локальные файлы после закрытия приложения выбираются повторно.

## Приёмка

Сборка Windows должна пройти проверки логики, реального звука в Chromium и
нативного EXE в Windows/WebView2 перед передачей. Браузерный IPC-стенд отдельно
обозначается имитацией. Windows 10, два монитора и реальный VK пользователя
требуют физической проверки; стенд Windows Server 2022 их не заменяет.
Ранее сообщённые сбои фонового окна/рекламы и отдельных VK-сетов не объявляются
исправленными этим изменением интерфейса.

### Состояние рабочей версии на 7 ноября 2026

Реализация подготовлена локально в feature/desktop-dj-compact-themes на основе
8151483da49e1cce5ef82ace90044a771d61c8d1. Прошли 53 проверки логики npm test,
проверки синтаксиса JavaScript, согласованности версии и нативного генератора;
изменённые Python-сценарии компилируются без ошибок.

Браузерные проверки не выполнены: установленный Chromium не запускается из-за
запрета локального сокета; облачный браузер запрещает file://. Эти попытки
не являются проверкой интерфейса или звука. Получить headless-shell также
не удалось. Проверка CSS отдельным парсером не выполнена: модуль отсутствует.

Загрузка исходников, тестов и workflow в GitHub отклонена автоматической
проверкой из-за отсутствия отдельного разрешения на передачу. Удалённая ветка
с этими изменениями не создана, Actions не запускался, нового EXE пока нет.
Подготовлен workflow: браузерный PCM/темы/сеты, старые DSP-сценарии и нативный
Windows EXE/фон. После разрешения отправить код нужно выполнить эти проверки,
исправить выявленные ошибки и только затем передавать сборку пользователю.
