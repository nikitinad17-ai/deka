# Deka Desktop 0.12.0 — Vinyl, drag & drop, tempo and VK library

30 октября 2026, Москва. Основа: проверенная Алексом Windows 0.11.0, ветка `feature/desktop-dj-0.11.0`, ревизия `7acc16142e5be869843397044b61953038222e6e`. Рабочая ветка: `feature/desktop-vinyl-0.12.0`. Независимые ветки Deka2 не затрагиваются.

## Управление

- Пластинка: зажать левую кнопку — остановить; вращать по/против часовой стрелки — слышимый скретч вперёд/назад; отпустить — продолжить с изменённого места. На паузе после отпускания остаётся пауза. Отмена жеста/потеря фокуса не оставляет деку зажатой и не запускает её неожиданно. Колесо и стрелки по-прежнему перематывают по секунде.
- Первый захват готовит PCM выбранного файла; показывается «Готовлю скретч…». До готовности удержание останавливает транспорт, затем доступно звуковое вращение. Декодируется только выбранная дека по первому касанию, не вся библиотека. Кэш ограничен 256 МиБ PCM/деку и 100 МиБ исходного файла. Длинные записи остаются доступны обычному плееру; для их скретча выводится явная ошибка. Смена/удаление трека освобождает PCM и отменяет ожидание старого файла.
- Из Проводника можно бросать файлы или папки на пульт/библиотеку. На A/B — импортировать и загрузить первый аудиофайл в выбранную деку, остальные остаются в библиотеке. Внутри приложения строка перетаскивается на A/B. Нет автозапуска, замена играющего трека требует подтверждения. Повторный импорт того же имени/размера/даты не плодит копии. Папки читаются рекурсивно, максимум 5000 файлов/порцию, метаданные — максимум четырьмя источниками одновременно.
- Tauri `dragDropEnabled=false`: Windows отдаёт File/Directory DataTransfer браузеру вместо перехвата на нативном уровне. Случайный drop не уводит приложение на страницу файла.
- Темп ±8% с Key Lock (по умолчанию включён): скорость меняется с сохранением тональности через WebView2 `preservesPitch`. Без Key Lock темп меняет также высоту звука, как в 0.11.0. Это выбор режимов, а не обещание профессионального time-stretch. Исходный BPM задаётся вручную/TAP; рядом отображается BPM с учётом темпа и nudge. BPM не выдумывается, автоанализ и SYNC не добавлены.

## VK: перенос рабочего сценария APK 0.10.7

В APK вход выполняет отдельный чистый WebView; после входа основной открывает свою музыку, затем `DekaLibrary.collectMy` следует «Показать все» и догружает список. В Windows раньше была кнопка открытия `/audio` и обычный refresh: явного импорта полного личного списка не было, а завершение любого collect ошибочно запускало CSV-экспорт.

Теперь «Войти в VK» открывает отдельное окно `vk-login` без Deka scripts, с обычными настройками браузера и общим профилем куки. Приложение не читает ввод формы, не экспортирует и не журналирует куки. Нативный код проверяет только наличие session cookie и возврат на основной домен; значения остаются внутри процесса. Проверка выполняется вне UI-потока, поскольку синхронное чтение WebView2 cookies в callback может блокировать окно. После подтверждённой сессии окно закрывается, основное окно VK открывает `/audio#deka-library=collect`.

«Загрузить всю музыку» и «Моя музыка» вызывают тот же `collectMy`, что APK. Прогресс, отмена, полный/частичный список видны в Windows. События `library` отображаются в медиатеке, точный key передаётся при выборе трека. Импорт библиотеки не создаёт CSV сам: экспорт — только своей кнопкой. Вход через VK ID/пароль больше не выдаётся за успешную авторизацию по отсутствию кнопки «Войти».

**Загрузка VK здесь означает список и воспроизведение через VK, как в APK. Аудиофайлы VK не скачиваются и не становятся локальными источниками для скретча/DJ.**

## Архитектура и фактические проверки

Сохраняется общий MediaElement/WebAudio движок 0.11.0. При удержании MediaElement приостанавливается; выбранный PCM читает `vinyl-processor.js` в AudioWorklet с линейной интерполяцией и подписанной скоростью. Его выход входит в те же LOW/MID/HIGH, gain, crossfader, master и защиту. Возврат на обычный транспорт устанавливает итоговую позицию и сохраняет темп. Мышь задаёт положение с масштабом 1 оборот = 1.8 секунды; AudioWorklet сглаживает движение и отпускание. Не эмулируется аппаратный timecode-винил.

Референс — управление Vinyl и транспорт Traktor Pro 2, без установки старого стороннего бинарника и без копирования оформления:
- [Traktor Pro 2 — официальное руководство](https://www.native-instruments.com/fileadmin/ni_media/downloads/manuals/traktor/traktor_pro_2_manual_english.pdf).
- [Native Instruments: Mouse Control / Vinyl](https://docs.native-instruments.com/ni-tech-manuals/traktor-pro-manual/en/preferences).
- [Tauri: dragDropEnabled](https://v2.tauri.app/reference/config/#dragdropenabled).

Автоматическая проверка:
- `npm test`: прежние 20 модульных проверок, 4 проверки реального PCM-обработчика (тишина при удержании, обратный порядок асимметричного сигнала, реверс/границы, release/dispose), smoke с генератором Android.
- `tests/browser.py`: прежние 78 сценариев библиотеки, APK-входа и сетов на синтетической разметке.
- `tests/desktop_dj.py`: прежние 30 проверок звуковой смеси, A/B и 60 секунд одновременной игры; проверка смещения высоты теперь явно отключает Key Lock.
- `tests/desktop_vinyl.py`: настоящие pointer и DataTransfer события, остановка/звуковое движение пластинки с изолированным выходом A, обратный жест/продолжение/пауза/потеря фокуса/удаление, файлы и папки, независимая B, полный VK-list и отсутствие побочного CSV.
- Темп измеряется через UI на −8/−4/0/+4/+8%: наклон media-clock соответствует скорости, DFT 32768 отсчётов / 48 кГц подтверждает 660 Гц с Key Lock, 712.8 Гц при +8% без Key Lock. Сохраняется фактическое измерение аудиографа старого набора.

Отчёты в `test-output/`, CI прикладывает `browser-regression-results`. Это цифровой Chromium-выход и синтетические VK-страницы, не физическая Windows/звуковая карта и не реальная авторизация VK. Результат Windows-сборки проверяется отдельно в Actions. Android APK из этой ветки не выпускается. Слияние и публикация release не выполняются.

## Приёмка на Windows

1. Запустить 0.12.0. Перетащить два файла из папки; одну строку бросить на A, другую на B. Запустить обе.
2. Зажать A: A остановилась, B продолжает. Повращать вперёд/назад: слышен скретч. Отпустить: A продолжает с новой позиции. Повторить на паузе; пауза сохраняется.
3. Проверить темп −8/0/+8%, Key Lock вкл/выкл, nudge с отпусканием, CUE и crossfader. Проверить MP3 и свой привычный формат.
4. VK Музыка → «Войти в VK» → обычный вход VK → автоматический возврат → «Загрузить всю музыку». Проверить последние треки, play/pause, существующие сеты и повторный запуск приложения с сохранённой сессией.
5. Если VK не вернулся автоматически, закрыть окно входа вручную, открыть «Окно ВК», убедиться в авторизации и нажать «Загрузить всю музыку». Сообщить этап сбоя без пароля или cookies.
