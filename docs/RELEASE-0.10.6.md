# Дека 0.10.6 — весь список «Мои треки» и вход только через окно входа

По «Отчёту» из 0.10.5 видно: на m.vk.ru/audios<id> 24 строки, из них 6 — «Мои треки», 18 — рекомендации (их отсекли правильно). У раздела есть «Показать все», но 0.10.5 переходила по нему, только если ссылка вела на /audios<id> другим адресом. Поэтому загрузилось 6.

## Список

- **«Показать все» раздела «Мои треки»** теперь срабатывает в любом виде: кнопка без адреса или ссылка на эту же страницу нажимается, и VK раскрывает список на месте. Ссылка на другой адрес музыки VK (/audio…, /music…) открывается, и сбор продолжается там. Если такой кнопки нет, ссылкой считается заголовок раздела «Мои треки ›». Переходы ограничены, чтобы не ходить по кругу.
- **Включение трека во время загрузки** больше не обрывает её, если трек уже на экране. Если трек пришлось искать прокруткой, статус честный: «загрузка прервана: включён трек», а не «остановлена вами».

## Вход

- **Только через окно входа «Деки».** Кнопки «Войти»/«Зарегистрироваться» на сайте VK внутри «Деки» (без сессии) открывают окно входа. Если основное окно само попало на страницу входа VK (id.vk.ru, /login, /join, /restore, /auth…), тоже открывается окно входа. Исключение — если его закрыли меньше минуты назад.
- **Проверка VK «Продолжить»** (challenge/checkpoint) остаётся в основном окне: её надо проходить там, окно входа на ней не открывается.
- **Окно входа закрывается только при настоящей сессии** (кука `remixsid`). В журнале 0.10.5 видно, что VK однажды вернул на сайт без входа, и окно закрылось раньше времени.

## Проверки

20 модульных сценариев и 75 браузерных проверок. Новые: превью из 6 треков со ссылкой в заголовке ведёт к полному списку (95 из 95); «Показать все» на той же странице раскрывает список на месте (95 из 95, без рекомендаций); включение видимого трека не прерывает загрузку; кнопки входа VK открывают окно входа «Деки»; страница входа в основном окне открывает окно входа; проверка «Продолжить» его не открывает.
