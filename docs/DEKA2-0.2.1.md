# Дека 2 0.2.1 — исправление своего VK и запуска треков

## Исправления
- Не используем `vk.user.id` (может быть просмотренный профиль) как аккаунт входа. Противоречащие друг другу ID блокируют загрузку вместо угадывания. ID сессии виден на экране; есть переход к профилю в настоящем VK.
- Рекомендации на `/audio` и чужие `/audios...` не выдаются за личную библиотеку. В личном списке исключаются распознанные рекомендательные секции. Если аккаунт неизвестен, не показывается чей-либо кэш.
- Новый кэш v3 привязан к аккаунту и собственной странице. Старый непроверенный кэш остаётся нетронутым, но не импортируется. Неполный проход не обрезает сохранённый хвост.
- Для сохранённого трека сначала открывается его собственная библиотека, а не поиск среди рекомендаций. Сохраняются выбранный трек и дека A/B при навигации; намерение ограничено аккаунтом и двумя минутами.
- ID с префиксом `audio` и кнопка вокруг строки поддерживаются. Клик без реального запуска больше не считается успехом. Подтверждение требует нативного события playing, готового медиа и продвижения времени; при наличии метаданных они сверяются с треком.
- Исправлено продолжение после паузы без повторного клика/перезапуска. Смена аккаунта очищает загруженные VK-деки, не удаляя локальные файлы и сохранённую библиотеку старого аккаунта.
- VK оставлен на нативном аудиовыходе. Его blob/MediaSource больше не захватывается в дополнительный AudioContext. EQ и фильтры VK отключены явно; фейдеры, Master, Mute и темп сохраняются. Для локальных файлов остаются обе независимые деки и эффекты.

## Проверки
24 модульных сценария и 71 браузерная проверка: 15 библиотека/поворот + 30 фейдеры/микшер + 26 аккаунт/запуск/продолжение. Дополнительно синтаксис, изоляция приложения, генератор Android, нативные сборки в CI.
Тесты без настоящего VK-аккаунта: синтетическая разметка и идентификаторы, настоящий HTMLMediaElement и WebAudio Chromium. Не заменяют проверку сессии пользователя на физическом телефоне. Собственный полный плейлист по-прежнему зависит от живой разметки VK.

## Установка
Обновление «Дека 2» 0.2.0, а не первая Дека. ApplicationId `ru.deka2.player`, versionCode 2001. Только подписанный существующим ключом Deka2-0.2.1.apk является установщиком. Неудаляемые данные и профиль приложения сохраняются при совместимой установке поверх старого приложения.
После обновления: Войти VK → проверить свой аккаунт → Моя библиотека VK → Загрузить всё. Первую Деку и main этот выпуск не изменяет.
