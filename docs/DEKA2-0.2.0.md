# Дека 2 0.2.0

Отдельное приложение `ru.deka2.player`; первая Дека и ветка main не затрагиваются.

## Изменения
- Windows-установщик создаёт ярлык «Дека 2» на рабочем столе текущего пользователя; CI проверяет реальную установку и цель ярлыка.
- VK: распознавание страницы входа без чтения значений логина/пароля; форма не перекрывается пультом. Сессией управляет WebView/VK, cookie поддерживаются.
- После входа открывается собственная библиотека; сохранённый список восстанавливается на стартовой странице. Кэш изолирован по ID пользователя. Частичная загрузка не стирает сохранённый хвост.
- Канальные фейдеры A/B, Master, Mute, кроссфейдер с точными нулями и короткими плавными переходами. VK получает выбранный уровень при создании следующего медиаэлемента, а не только в момент движения фейдера.
- Показания уровней для своих файлов, числовые значения регуляторов, сброс микшера, сохранение Master/каналов/EQ.
- Дополнительно: темп ±16%, три горячие точки на деку, петли 4/8 секунд для своих файлов, фильтры A/B. Нет фиктивной кнопки SYNC и обещаний автоматического BPM.

## Проверки
24 модульных сценария, 15 прежних браузерных проверок библиотеки и 30 новых проверок микшера/входа.
Новые проверки измеряют реальный сигнал WebAudio: нулевые каналы, Master, края кроссфейдера, независимость каналов. Проверяются реальный HTMLMediaElement VK-адаптера, наследование уровня следующим треком, владение VK-потоком декой B, горячая точка, петля и состояние входа, включая отдельную страницу VK ID.
Все данные VK и URL в тестах синтетические, проверка выполняется без сетевых запросов. Реальная сессия пользователя, его полный список и физический сон телефона не проверены. Полнота живого списка подтверждается только сравнением со счётчиком VK; остановка загрузки без подтверждения не выдаётся за полный список.

## Установка
Windows: `Deka2-setup.exe`, ярлык создаётся автоматически. Войти через «Войти VK», затем открыть «Моя библиотека VK». Данные 0.1.0 сохраняются в том же профиле приложения.
Android: версия 0.2.0 должна иметь тот же сертификат, что 0.1.0, и versionCode 2000 вместо 1000. Неподписанный CI-артефакт не является установщиком. Подпись выполняется защищённым существующим ключом, а не новым/раскрытым ключом первой Деки.

## Границы
Два локальных файла сводятся одновременно. VK остаётся одним общим потоком, назначенным A либо B. Нельзя выдавать два списка за одновременное сведение двух VK-песен. Петли HTMLMediaElement не являются сэмпл-точным профессиональным аудиодвижком. Фильтры/EQ для VK зависят от доступности WebAudio для потока.
