# Дека 2 0.2.2 — продолжение личного списка без рекомендаций

Этот выпуск исправляет конкретный сценарий: первые личные треки видны, продолжение не загружается, а соседние рекомендации попадают в коллекцию. Новый DJ-функционал не добавлялся.

## Изменения

- Граница списка определяется ближайшим предшествующим заголовком/контейнером, а не первым заголовком общего родителя. Распознаются соседние рекомендации, маркированные контейнеры и отдельные блоки.
- Перед сканированием раскрывается личное «Показать все» или открывается его проверенная ссылка. Догрузка поддерживает ссылки и role=button, а не только button. Чужие ссылки и пагинация рекомендаций не выбираются.
- overflow:hidden не выбирается вместо прокручиваемого родителя. Настоящий scroll host закрепляется на время прохода, чтобы исчезающие виртуальные строки не переключали его на документ.
- Граница прохода учитывает личный список и его loading sentinel, а не бесконечную ленту рекомендаций ниже. Догрузка собственного блока вызывается до достижения конца всей страницы.
- Поддерживается явно выбранная личная вкладка и личный раздел /audio?section=my; общий /audio без личного контекста остаётся закрытым для импорта.
- Полный список подтверждается только совпадением собственного счётчика. Окончание прокрутки без счётчика остаётся неполным результатом.
- Промежуточно найденные треки сохраняются; прерванная повторная загрузка не обрезает сохранённое продолжение. Кэш v3 мог содержать рекомендации: он не удалён, но автоматически в новый отфильтрованный v4 не переносится.
- Унаследованная локальная HTML-страница больше не содержит каталог синтезированных демопесен в собранном приложении. Основной двухдековый интерфейс этот каталог и раньше не использовал.
- Во время сбора исходная страница VK видна, пульт не закрывает её; есть остановка и отдельная кнопка «Список в VK». «О списке» показывает безопасную техническую сводку без cookie, паролей, токенов или названий песен.

## Проверки

24 модульных сценария; сохранены прежние браузерные проверки библиотеки, микшера и VK-воспроизведения. Дополнительно 21 проверка границ: плоские соседние заголовки, 12-трековый preview, 160 личных треков с догрузкой, 55 треков с пагинацией ссылкой, реальный IntersectionObserver для 60 треков, исключение рекомендаций, личный счётчик, независимая кнопка просмотра VK и возврат списка после сбора.

Это синтетические страницы с реальным Chromium DOM/аудио, не проверка аккаунта пользователя. Исправлены воспроизведённые ошибки кода; полноту живого VK-списка на телефоне ещё нужно подтвердить. Ни музыка пользователя, ни чужие демотреки не вшиваются в приложение.

## Установка

ru.deka2.player, versionName 0.2.2, versionCode 2002. APK для установки должен быть подписан существующим ключом Деки 2. Старое приложение не удалять. При первом запуске личный список собирается заново из VK, чтобы рекомендации старого кэша не вернулись. main первой Деки не изменяется.
