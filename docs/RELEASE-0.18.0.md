# Дека Desktop 0.18.0 — фактический отчёт

1 ноября 2026 года. Основа: проверенная Desktop 0.17.0. Исходный коммит EXE `7844358154a7a9122cb2a47a3b691d20b4d8269b`. [Сборка 41284682646](https://github.com/nikitinad17-ai/deka/actions/runs/41284682646), [ветка и PR 15](https://github.com/nikitinad17-ai/deka/pull/15).

Пройдено **419 проверок quality** (44 Node и 375 браузерных), **138 проверок внутри готового EXE** и **6 проверок длительного прогона с реверсами** — всего 563. Повторы не прибавлены к числу проверок. Нативная среда: Edg/156.0.4314.50, обычный пользователь Windows, integrity 8192, elevated=false, restricted=false.

Внешние панели «Реверс» расположены независимо: A слева, B справа. Каждая имеет 1,5 / 2,5 / 3,5 с; общего переключателя A/B нет. Обычное нажатие полностью выполняет эффект. При включённом AUTO MIX заранее готовый локальный трек другой деки входит до остановки исходной; при выключенном эффект останавливает только выбранную. Это согласованное уточнение второго файла, применённое также к Desktop. Воспроизведение назад не добавлено.

В Windows проверены все шесть направлений/длительностей с включённым автомиксом и шесть с выключенным. При входе используется активная CUE, включая 00:00; уже играющий целевой трек не перематывается и не получает второй play. Громкость и бас плавно вводятся за длительность эффекта. Минимальные RMS шести переходов: 0.031769, 0.034586, 0.034307, 0.039230, 0.036987, 0.037715; обнаруженных выпадений звука нет. Остановки совпали с 1,5 / 2,5 / 3,5 аудиосекунды; падение высоты PCM проверено при включённом и выключенном Key Lock. Повторные нажатия заменяют один эффект и не перезапускают входящий трек.

Пустая/недоступная другая дека выдаёт подсказку до остановки текущего трека. Долгий play-promise оставляет текущую музыку играть до готовности целевого трека; Pause both отменяет ожидание без позднего запуска. Уже законченный трек другой деки не считается подготовленным. Длительный прогон обнаружил границу завершения обычного сведения, при которой старый завершённый файл ещё находился в слоте; добавлена проверка completed/ended. После подготовки следующего файла реверс работает. Проверена передача управления от уже идущего 17-секундного сведения к реверсу с сохранением целевой позиции и выходом баса к выбранному EQ.

SHUF проверен кнопками обычного плеера и DJ: меняется реальный аудиоисточник и выбирается случайный следующий файл. В 0.17 переключение SHUF отменяло активное сведение, поскольку повторная установка неизменённого REP также вызывала отмену. Исправлена идемпотентность флагов, SHUF сохраняет текущий переход и меняет дальнейшую очередь. При отмене отложенной загрузки очищаются также старые длительность, BPM и анализ; пустая дека не показывает данные предыдущего файла. REP 1 по-прежнему повторяет текущий трек.

Обычный автомикс, CUE, Key Lock, эффекты и скретч сохранены. Измеренные обычные переходы в EXE: 17.0187, 17.0560, 17.0347, 17.0160, 17.0480 с, включая возврат к обычному автомиксу после реверса. Проверены настоящие media clocks, BPM-подгонка, EQ, независимые эффекты, мышь, перетаскивание, основная очередь и совместимость Android-кода. APK в этом выпуске не собирается.

Длительный локальный прогон финального кода: 412.9 с, 19 последовательных запусков, 7 запросов реверса с длительностями 1,5 / 2,5 / 3,5 с среди обычных 17-секундных переходов. Минимальный RMS 0.03045976, пик 0.21803796. Все 12 файлов посещены по порядку и очередь вернулась к началу; ошибок UI и остановок звука не обнаружено. Подтверждено не менее пяти завершённых реверсов. Внешних перемоток в прогоне нет.

Проверены заново загруженные локальные MP3 и контролируемый недействительный старый blob-URL. Точное состояние личной библиотеки прежней версии недоступно; причина пользовательского наблюдения при восстановлении не установлена. Личные музыкальные файлы, физическое аудиоустройство и живой аккаунт VK не проверялись. VK остаётся одним последовательным потоком; реверсное DJ-сведение применяется к локальным файлам. Стабильный v0.17.0 сохранён, main не менялся.
