# Desktop 0.17.0 — BPM SYNC, CUE и торможение

Основа — проверенный Desktop 0.16.0; изменения только в Desktop. Рабочие механизмы очереди, completed/поколения событий, два независимых HTMLMediaElement, скретч мышью, Key Lock и остальные эффекты сохранены.

BPM автомикса теперь определяется фактической скоростью уходящей деки. Входящая скорость рассчитывается в диапазоне ±8% с проверкой половинного/двойного BPM, удерживается все 17 секунд и сохраняется после сведения. При ненадёжном BPM или выходе за диапазон остаётся EQ/volume-переход с явным «Без BPM SYNC». Ручная поправка темпа получает приоритет и плавно меняет согласованные скорости; источник BPM/TAP участвует в следующем переходе. Фаза при уверенной оценке задаёт задержку запуска с точной CUE. Прежняя независимая sweep-кривая выключена в пользовательском Desktop; legacy-режим оставлен для совместимости.

Громкость и три полосы EQ управляются аудиочасами. Старт пересчитан на постоянную скорость: больше не используется окно, рассчитанное на торможение до 1/3. Входящие полосы начинаются с −6/−3/−3 dB, уходящие доходят до −12 dB. Для коротких файлов сохранено ограниченное окно фейда. Следующий трек заранее загружается и при выключенном AUTO MIX.

CUE имеет независимые наличие и стадию цикла: установить, вернуть с паузой, удалить. Нулевая позиция активна; загрузка другого трека сбрасывает метку. Неподвижная отметка отделена от указателя проигрывания.

Торможение — живой PCM в AudioWorklet с ограниченным четырёхсекундным кольцом. Скорость чтения и высота падают до нуля за выбранные 0,5/1/2 с, даже при Key Lock. Сохраняется фактическая достигнутая позиция. Повторное нажатие заменяет эффект; ручное торможение отменяет автомикс и оставляет деку припаркованной до Play. Параметры другой деки и кроссфейдер сохраняются. Полный файл для эффекта не декодируется.

Из FX изменены только Echo (четвертная задержка с фильтрованной ограниченной обратной связью) и Reverb (собственный стереоимпульс 3,6 с и новые dry/wet-кривые). Остальные эффекты и цвета/регуляторы сохранены. VK по-прежнему один поток: завершённый источник больше не получает лишнее поколение при штатном переходе на другую деку, что устраняет зависший starting-token. Живой аккаунт в этой среде не проверялся.

# Дека Desktop 0.17.0 — фактическая проверка

1 ноября 2026 года. Сборка из `8ae40b27c75ec3863c8524143b093cdb32f4c798`, [CI 41279896331](https://github.com/nikitinad17-ai/deka/actions/runs/41279896331), [исходники PR 14](https://github.com/nikitinad17-ai/deka/pull/14).

Пройдено **384 проверок quality** (44 Node и 340 браузерных), **103 проверок готового EXE в Windows**, **5 проверок длительного прогона** и **2 дополнительных сравнения всех положений Echo/Reverb** — всего 494. Повторные запуски одного сценария не прибавлены к сумме. Windows runtime: Edg/155.0.4283.62; EXE запущен обычным пользователем, integrity 8192, elevated=false, restricted=false.

В собранном EXE фактические переходы A→B и B→A занимали 17.0533, 17.0560, 17.0053, 17.0480 с. Частоты и громкость следуют одному 17-секундному аудиотаймеру, фактические скорости держат общий BPM на всём наложении. Пример 120/125 BPM даёт 1.0×/0.96×; после сведения 0.96× сохраняется. Проверены исходящая скорость +4%, TAP, половинный/двойной BPM, неизвестный ритм, выход за ±8%, ручное вмешательство и две уже играющие деки.

Записаны реальные каналы обеих дек с ударными, басом и аккордами. Медианное расхождение ударов в Windows: 12.17, 16.29 мс; максимальное — 16.69, 28.44 мс. CUE 00:30/01:10 сохранена точно; фазу корректирует время запуска, произвольной перемотки нет. Это измерение на ритмических тестовых композициях.

CUE проверена на обеих деках: поставить → вернуться → удалить, повторный цикл, активная 00:00, независимость A/B, сброс при другом треке. Автомикс стартует с активной метки после возврата; без метки/после удаления — с 00:00. Подсветка и неподвижный маркер проверены через интерфейс.

Торможения 0,5 / 1 / 2 с проверены на A и B. Фактический PCM падает по высоте при включённом и выключенном Key Lock. Конечная пауза, достигнутая позиция, CUE, Key Lock, возобновление, замена эффекта повторным нажатием и независимость второй деки проверены. Проверены отмена ожидающего старта и торможение во время сведения в обеих ролях; кроссфейдер и параметры другой деки сохраняются. Естественное окончание другой деки продолжает её очередь, остановленная дека остаётся припаркованной.

Echo и Reverb сравнены с 0.16 на одинаковом PCM при 10/50/100%. Хвосты усиливаются с ползунком, пики остаются ниже перегрузки. Flanger/Filter/Phaser дают побайтно совпадающий float PCM в сравнительном тесте. Скретч мышью и Roll проверены в готовом EXE. Для прослушивания приложен WAV из девяти фрагментов по 4,5 с: сухой звук; старый Echo max; новый Echo 10/50/100%; старый Reverb max; новый Reverb 10/50/100%.

Локальный непрерывный MP3-прогон: 413.2 с, 17 запусков, все 12 треков по порядку и возврат к началу. Минимальный RMS 0.03752516, пик 0.22055918; обнаруженных выпадений сигнала и ошибок UI нет. Прогон выполнен без перемоток и сокращения 17-секундных фейдов на исходной ревизии `73f27bf41f075d5ffe242129a5795cd49498539b`; содержимое src, src-tauri и package.json совпадает с собранной ревизией `8ae40b27c75ec3863c8524143b093cdb32f4c798`. Следующее изменение задаёт UTF-8 для сравнительного теста в Windows. Идентичность кода приложения проверяется по Git-объектам при публикации.

При проверке совместимости обнаружено отсутствие предзагрузки при выключенном AUTO MIX; прежнее поведение восстановлено. Сохранено короткое окно перехода для клипов, которые не вмещают 17 с. Все 29 сценариев continuous и 19 сценариев прежнего режима сведения пройдены. В VK исправлен незавершённый токен последовательного перехода: смена общего потока больше не инвалидирует уже законченный источник. Управляемый мост проверяет A→B→A, точные ключи и защиту от повторного ended. Два потока VK не добавлены.

Ограничения: собственные музыкальные файлы, субъективное звучание и физическое аудиоустройство пользователя здесь не проверялись. Живой аккаунт VK не использовался. Автоматическая оценка BPM/фазы подходит не для любого жанра; при недостаточной уверенности или выходе за ±8% интерфейс явно показывает отсутствие BPM SYNC. Короткие файлы сокращают фейд. В тестовой 0.16 переход уже измерялся около 17 с; пользовательское наблюдение около 10 с на его компьютере здесь не воспроизведено. В 0.17 окно старта пересчитано для постоянного общего BPM, прежнее замедление до 1/3 отключено в Desktop.

Это Desktop, без нового APK. Стабильный [v0.16.0](https://github.com/nikitinad17-ai/deka/releases/tag/v0.16.0) сохранён. Main не менялся.
