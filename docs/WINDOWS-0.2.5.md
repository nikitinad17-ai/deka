# Дека 2 0.2.5 — исправления источника Windows

Собственный плеер и окно VK остаются раздельными. Профиль ru.deka2.player не меняется. Новых DJ-функций нет, APK не собирается, main первой Деки не затрагивается.

## Исправления

1. Перед sync/playKey оболочка показывает и разворачивает окно-источник, затем возвращает фокус собственному плееру. Документ VK больше не скрывается сразу после определения аккаунта. Во время импорта кнопка возврата не скрывает источник. Окно источника остаётся вспомогательным; собственный плеер не пересоздаётся.
2. Команда синхронизации, пришедшая до DOMContentLoaded, ожидает готовности, а не теряется с ложным успешным ответом.
3. При медленной отрисовке страницы сборщик сначала ждёт строки, затем выбирает фактический scroll host. Прежний вариант закреплял documentElement до появления внутреннего списка.
4. Редакционные карточки без аудиострок тоже ограничивают личную секцию: их «Показать все»/«Показать ещё» не выбирается как её продолжение.
5. Промежуточное пустое уведомление после перехода источника не стирает уже полученные строки в плеере и не завершает активную загрузку. Смена подтверждённого аккаунта очищает его представление.
6. Отмена прерывает также отложенные переходы и повторные попытки. При остановке прогресса загрузка завершается с ошибкой, не с фальшивым полным списком.
7. «О списке» на Windows показывает сохраняемый безопасный JSON: количество, готовность/видимость источника и причина остановки. Ни паролей, ни cookie/токенов, ни ID аккаунта, ни названий треков и URL в отчёт не включаются.

## Проверки

31 модульный сценарий, прежние проверки двух локальных дек/фейдеров, собственных и посторонних секций, 1000 виртуализированных строк. Добавлены редактированные страницы с карточками без треков и с отложенным монтированием настоящего прокручиваемого блока. Эти сценарии воспроизвели ошибки предыдущего кода и проходят после изменения.

Windows CI устанавливает полученный EXE, запускает именно установленный файл, проверяет два настоящих WebView2 и Tauri IPC, 240 личных строк с IntersectionObserver, выбор последнего трека, громкость/паузу/продолжение. Для проверки чувствительности к visibility фикстура не догружает строки, когда document.hidden=true.

Данные VK и звук в автоматических проверках синтетические. Реальный VK-аккаунт пользователя не подключён к тестам. Успешный тест не доказывает полноту его живого плейлиста. Полный результат отмечается только при совпадении собственного счётчика источника. Два локальных файла независимы, VK остаётся одним потоком.

## Установка

Закрыть Деку 2, запустить Deka2-setup.exe поверх предыдущей версии. Ничего не удалять и не чистить профиль. Главным остаётся плеер; VK используется для входа и сбора. При активном импорте не сворачивать/закрывать вспомогательное окно VK. Уже найденные треки появляются в плеере постепенно.
