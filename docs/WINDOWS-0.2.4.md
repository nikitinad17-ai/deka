# Дека 2 0.2.4 — собственный Windows-плеер

Исправление по скриншотам: Главная VK содержит личный preview «Мои треки», но прежний адаптер требовал личную страницу до нажатия «Показать все». Теперь сначала определяется именно личный блок и его реальная ссылка/кнопка. Общий discovery-список не импортируется. Переход ограничен подтверждённым аккаунтом, origin, безопасными музыкальными URL и временем.

Дополнительно исправлена гонка: запоздалое уведомление о SPA-навигации отменяло уже начавшийся проход нового списка. Старые операции и операции нового источника теперь различаются.

На Windows окно main — собственная локальная страница desktop.html. VK находится в отдельном окне vk и передаёт сессию, личную библиотеку и состояние аудио. Навигация источника не пересоздаёт плеер, не закрывает списки и не теряет локальные деки. Вход осуществляется на самом VK. Пароли и токены не передаются в окно плеера. Удалённое окно имеет только права отправки событий; команды оболочки проверяют локального вызывающего.

Версия Windows 0.2.4 сохраняет ru.deka2.player. Приложение и данные не удалять. APK в этом изменении не собирается, первая Дека и main не меняются.

Тесты: регрессия Главная → 12 личных треков → Показать все → 75 треков. Полный сценарий двух документов: 240 личных треков с реальной догрузкой IntersectionObserver, последний трек через команду источника, громкость/пауза/возобновление и сохранение списка при перезагрузке источника. Windows CI дополнительно запускает установленный EXE и проверяет настоящий канал Tauri/WebView2, а не только JS-макет.

В тестах VK подменён заранее заданной страницей, звук локальный тестовый. Это не проверка живого аккаунта пользователя, доступности всех вариантов VK-разметки или полной библиотеки пользователя. Успешный нативный тест и реальная пользовательская проверка — разные этапы. Полнота сборщика утверждается только при совпавшем счётчике источника.
