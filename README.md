# Дека 2 · 0.2.2

Исправление продолжения личного списка и исключения рекомендаций. Подробности: `docs/DEKA2-0.2.2.md`. Не добавляет новых DJ-возможностей.

# Предыдущая версия 0.2.1

Отдельный плеер `ru.deka2.player` для Windows и Android. Исходники находятся в ветке `deka2`; первая Дека, её данные, релизы и ветка `main` не изменяются.

## Установка

Windows: запустить `Deka2-setup.exe`. Установщик создаёт ярлык «Дека 2» на рабочем столе текущего пользователя; CI проверяет установку, наличие ярлыка и существование его цели. `Deka2.exe` — отдельный исполняемый файл без установки.

Android: использовать только подписанный `Deka2.apk`. Версия 0.2.1 имеет versionCode 2001; для обновления 0.1.0/0.2.0 нужен тот же действующий сертификат. CI не создаёт новый ключ вместо существующего: без GitHub Secrets он выпускает **неустановочный** `Deka2-unsigned.apk` для защищённой подписи владельцем вне CI. Это не Deka Preview и не обновление первой Деки.

## VK и библиотека

Вход происходит на настоящей странице VK/VK ID, без своей формы пароля. Пульт не должен перекрывать обнаруженную форму входа. После авторизации доступна кнопка «Моя библиотека VK», автоматическая попытка загрузить собственную музыку и восстановление сохранённого списка при следующем запуске.

Список берётся только со страницы музыки определённого аккаунта, а не из рекомендаций или чужого профиля. Непроверенный кэш версий до 0.2.1 не импортируется автоматически; он не удаляется. ID аккаунта показан в библиотеке. Список накапливается по стабильным идентификаторам. Неполная загрузка не удаляет ранее сохранённые треки; есть прогресс, отмена и различение подтверждённого количества и неполного прохода. Кэш разделён по пользователю и источнику. Загрузка живого плейлиста зависит от доступной разметки и сессии VK; полноту именно вашего списка нужно сверять со счётчиком VK.

## DJ

При горизонтальном положении — две вертушки A/B с независимыми списками и поиском. Канальные уровни, Master, Mute и кроссфейдер воздействуют на аудио; громкость VK сохраняется при замене медиаэлемента. Добавлены темп ±16%, три горячие точки, фильтры и петли 4/8 секунд для локальных файлов.

**Два локальных файла играют независимо. VK остаётся одним общим потоком, назначенным A или B. Две песни VK одновременно не сводятся.** Для надёжности VK воспроизводится напрямую без подключения к WebAudio Деки. EQ/фильтры теперь доступны только для своих файлов; фейдеры, Master, Mute и темп VK сохранены. Автоматический BPM/SYNC не реализован, а петли файлов не являются сэмпл-точными.

## Проверки

`npm test`: синтаксис, версия, изоляция приложения, генератор Android и 24 модульных сценария.

`python tests/browser.py`: 15 проверок библиотеки и ориентации, включая 1000 виртуализированных строк.

`python tests/vk-reliability-browser.py`: 26 проверок аккаунта, личной библиотеки, подтверждённого старта и продолжения песни.

`python tests/mixer-browser.py`: 30 проверок, включая измеренный сигнал WebAudio, реальные элементы HTMLMediaElement с тестовым звуком, нулевые положения фейдеров, общий поток VK и не перекрытую страницу входа.

Тесты полностью локальные: синтетические данные и URL, без входа в настоящий VK. Реальная сессия пользователя и физический сон телефона не проверены.

## Сборка

`npm install`, `npm test`, затем `npm run dev` или `npm run build`.

Браузерные проверки: `pip install -r tests/requirements.txt`, `python -m playwright install chromium`; для системного Chromium можно задать `CHROMIUM_PATH`.

`npm run prepare:brand` идемпотентно применяет имя приложения и префикс `deka2:`; запускается перед test/dev/build и перед Android init. Секреты подписи: `DEKA2_KEYSTORE_BASE64`, `DEKA2_KEY_ALIAS`, `DEKA2_KEYSTORE_PASSWORD`. Приватный комплект восстановления нельзя помещать в Git.

Подробности: `docs/DEKA2-0.2.1.md`.
