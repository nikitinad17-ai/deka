# Дека

Музыкальный плеер на Tauri 2 для Windows и Android: локальные файлы и управление VK во встроенном WebView.

## 0.9.0 — проверочная версия

Основная работа этого выпуска — длинный плейлист и горизонтальный DJ-экран. Список накапливается по стабильным ID, неполная загрузка не стирает сохранённый хвост. При повороте телефона видны две вертушки и два отдельных списка с поиском. В списках доступна вся собранная библиотека, а не только видимые строки страницы VK.

Два локальных файла воспроизводятся независимо, со своими EQ, CUE, уровнем и общим кроссфейдером. **У VK по-прежнему один общий поток**, переключаемый между A/B. Одновременного сведения двух VK-треков нет; интерфейс это прямо обозначает.

Подробности, границы проверки и установка: [docs/RELEASE-0.9.0.md](docs/RELEASE-0.9.0.md).

## Android: не удаляйте старую Деку

Если защищённая подпись не настроена, CI собирает **Deka-Preview.apk** с отдельным идентификатором `ru.volna.player.preview`. Это параллельная проверочная установка, не обновление поверх 0.8. Вход в VK выполняется заново; старая Дека и её данные остаются на месте.

Раскрытый signing key больше не извлекается из истории Git. Для постоянной подписи требуются GitHub Secrets `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEY_ALIAS`, `ANDROID_KEYSTORE_PASSWORD`. Preview использует временный ключ, который не публикуется и не сохраняется. Последующие preview-сборки могут потребовать переустановки только Preview.

## Структура

- `src/index.html` — прежний Windows-плеер и локальные файлы.
- `src/vk-bridge.js` — управление существующим плеером VK и его WebAudio-обработка.
- `src/library-engine.js` — тестируемый сборщик с явными состояниями завершения.
- `src/library-runtime.js` — адаптер DOM, кэш, навигация и поиск точного трека.
- `src/deck-engine.js` — две локальные аудиодеки и явно общий VK-поток.
- `src/virtual-list.js` — длинные списки без тысяч DOM-элементов и сброса прокрутки.
- `src/mobile-overlay.js` — библиотека и горизонтальная DJ-панель.
- `src-tauri/` — нативная оболочка; порядок внедрения скриптов зафиксирован.
- `tests/` — модульные тесты и браузерные сценарии на локальной синтетической разметке.

Фоновый Android service из 0.7 сохраняется. Работа на физическом телефоне и с живой VK-сессией требует отдельной проверки; тестовая разметка не подтверждает все варианты интерфейса VK.

## Разработка

Для Windows нужны Node.js, Rust и C++ Build Tools. В корне проекта:

```sh
npm install
npm test
npm run dev
npm run build
```

`npm run build` создаёт `Deka.exe` и `Deka-setup.exe`. Существующие `update.cmd`/`update.ps1` оставлены для локальной разработки.

Браузерные проверки:

```sh
python -m pip install -r tests/requirements.txt
python -m playwright install chromium
python tests/browser.py
```

Тесты не заходят в VK и не требуют учётной записи. Результат и снимки экрана записываются в `test-output/`. GitHub Actions выполняет проверки до сборок Windows/Android. Проверочный релиз публикуется только из `main`, после успешных заданий.
