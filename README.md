# Дека

Ретро-плеер для Windows: свои файлы плюс VK Музыка во встроенном окне.

## Как устроено

- `src/index.html` — интерфейс плеера: дисплей, спектр, эквалайзер, плейлист.
- `src/vk-bridge.js` — скрипт внутри окна vk.ru. Читает трек, время и список треков со страницы и нажимает кнопки плеера ВК. Пароль не видит, ничего не скачивает.
- `src-tauri/` — оболочка на Tauri 2 (Rust). Создаёт два окна: плеер и скрытое окно ВК.

Вход в ВК сохраняется между запусками. Закрытие окна ВК только прячет его, музыка продолжает играть.
Внутренний идентификатор приложения остался `ru.volna.player`: так сохраняются вход в ВК и настройки, сделанные ещё в «Волне».

## Обновление одной кнопкой

1. Скачайте новый `deka.zip` в «Загрузки».
2. Дважды щёлкните ярлык «Обновить Деку» (или `update.cmd` в папке проекта).

Скрипт закроет «Деку», распакует самый свежий `deka*.zip`, соберёт и запустит плеер.
Готовый плеер всегда лежит в корне папки: `Deka.exe`, установщик: `Deka-setup.exe`.
На рабочем столе появляются ярлыки «Дека» и «Обновить Деку».

## Сборка на Windows

Один раз установить:

1. Node.js LTS: https://nodejs.org
2. Rust: https://rustup.rs (при установке согласиться поставить Visual Studio C++ Build Tools)
3. WebView2 уже есть в Windows 10 и 11.

Затем в папке проекта:

```
npm install
npm run dev      # запуск для проверки
npm run build    # сборка, Deka.exe появляется в корне папки
```

## Сборка в облаке (GitHub Actions)

`.github/workflows/build.yml` на каждый push в `main` собирает Деку для Windows и Android и выкладывает в Releases:
`Deka-setup.exe`, `Deka.exe` и `Deka.apk`. Версия релиза берётся из `package.json`, поэтому для новой версии её нужно поднять.

Ключ подписи Android лежит в `android/` (репозиторий приватный). Один и тот же ключ нужен, чтобы новые .apk ставились поверх старых.
Если ключ потерять, придётся удалить приложение с телефона и поставить заново.

## Android

Первая версия: свои файлы, эквалайзер и спектр. VK Музыка на телефоне — в следующих версиях.

## Первый запуск

1. Вкладка «VK Музыка» → кнопка «Окно ВК» → войти в аккаунт.
2. Открыть нужный раздел или плейлист ВК. Список появится в «Деке», раздел выбирается в выпадающем списке.
3. Клик по треку в «Деке» запускает его в ВК. Кнопки, перемотка, громкость, клавиши и эквалайзер работают для ВК.
4. «Экспорт списка» сохраняет исполнителей и названия выбранного раздела в CSV в «Загрузки».
5. Поле «Ссылка на трек или плейлист ВК» добавляет трек по ссылке в раздел «Добавлено по ссылке».

## Если список ВК пропал

ВК иногда меняет вёрстку. Разметка, под которую написан мост, проверена 27.09.2026: строки `[data-testid=MusicTrackRow]`. Если список перестал читаться, правка нужна только в `src/vk-bridge.js`, функция `readRows`.

## Если музыка ВК не играет

С включённым VPN ВК может не отдавать музыку (трек стоит на 0:00 в самом окне ВК). Нужно пустить «Деку» мимо VPN: раздельное туннелирование для `msedgewebview2.exe` или для доменов vk.ru и vk.com.
