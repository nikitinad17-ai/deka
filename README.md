# Дека

Музыкальный плеер на Tauri 2 для Windows и Android: локальные файлы и управление VK во встроенном WebView.

## 0.11.0 — Desktop DJ (проверочная ветка)

Кнопка **DJ · A/B** открывает две независимые деки для локальных файлов. Общий плейлист, поиск, «В A» / «В B», Play/Pause, seek, транспортный CUE, темп ±8%, временный nudge, ручной BPM/TAP, LOW/MID/HIGH, уровни каналов, равномощный crossfader, master и измерители сигнала.

Основа — вся ветка 0.10.7, включая полный список VK и сеты. Обычный плеер сохранён. При входе в DJ обычное воспроизведение ставится на паузу, при выходе обе деки ставятся на паузу. Выбор файлов в DJ не запускает их автоматически. В DJ конец трека не включает следующий. Темп меняет высоту звука; CUE не означает отдельное прослушивание наушников. VK остаётся обычным плеером, без двухпоточного сведения.

После закрытия приложения локальные файлы нужно выбрать снова. Поддержка MP3/WAV/FLAC/OGG/M4A/AAC/Opus зависит от кодеков WebView2; неподдерживаемый файл показывает ошибку. Аудиофайлы никуда не загружаются.

Проверки и ограничения: [docs/DJ-IMPLEMENTATION.md](docs/DJ-IMPLEMENTATION.md). Для Windows Actions создаёт `Deka.exe` и `Deka-setup.exe` в артефакте `deka-windows`; эта ветка не публикует релиз и не собирает APK.

## 0.10.7 — полный список по «Показать все»

Страница, куда ведёт «Показать все» своего раздела «Мои треки», считается полным списком при любом адресе и запоминается; сбор ждёт отрисовки VK. Подробности: [docs/RELEASE-0.10.7.md](docs/RELEASE-0.10.7.md).

## 0.10.6 — весь список и вход только через окно входа

«Показать все» раздела «Мои треки» срабатывает в любом виде (кнопка, ссылка на эту же или другую страницу, заголовок-ссылка); включение трека не обрывает загрузку; любые кнопки и страницы входа VK внутри «Деки» ведут в окно входа. Подробности: [docs/RELEASE-0.10.6.md](docs/RELEASE-0.10.6.md).

## 0.10.5 — свой экран входа

Без входа «Дека» показывает свой экран «Вход в VK». «Войти в VK» открывает отдельное чистое окно входа (обычный встроенный браузер без добавок «Деки»), которое закрывается само после входа; сайт VK — отдельной кнопкой. Подробности: [docs/RELEASE-0.10.5.md](docs/RELEASE-0.10.5.md).

## 0.10.4 — вход в VK во встроенном браузере

Окну VK ID разрешены куки, VK видит обычный мобильный Chrome, ссылки `intent://` открываются по запасной веб-ссылке, язычок «← Дека» стал кнопкой Android (на странице VK нет ничего от «Деки»), в «Отчёте» есть журнал входа. Подробности: [docs/RELEASE-0.10.4.md](docs/RELEASE-0.10.4.md).

## 0.10.3 — вход в VK и возврат из VK

На страницах входа VK «Деки» нет, без входа VK открыт целиком, после входа «Дека» сама открывает и загружает «Мои треки». В режиме «VK» сбоку язычок «← Дека». Подробности: [docs/RELEASE-0.10.3.md](docs/RELEASE-0.10.3.md).

## 0.10.1 — фон и полный список

На Android музыка и сеты продолжают играть при выключенном экране. «Треки VK» — только ваш список «Мои треки», целиком, без рекомендаций с главной страницы VK. Подробности: [docs/RELEASE-0.10.1.md](docs/RELEASE-0.10.1.md).

## 0.10.0 — сеты VK Видео

Сет из VK Видео слушается как аудио на экране «Деки»: продолжение с места остановки, треклист по таймкодам из описания (или свой), переход по трекам сета кнопками ⏮ ⏭. В версии для Windows это вкладка «Сеты» в медиатеке. Звук не скачивается: хранится только ссылка, название, место и треклист.

Подробности: [docs/RELEASE-0.10.0.md](docs/RELEASE-0.10.0.md).

## 0.9.0 — проверочная версия

Основная работа этого выпуска — длинный плейлист и горизонтальный DJ-экран. Список накапливается по стабильным ID, неполная загрузка не стирает сохранённый хвост. При повороте телефона видны две вертушки и два отдельных списка с поиском. В списках доступна вся собранная библиотека, а не только видимые строки страницы VK.

Два локальных файла воспроизводятся независимо, со своими EQ, CUE, уровнем и общим кроссфейдером. **У VK по-прежнему один общий поток**, переключаемый между A/B. Одновременного сведения двух VK-треков нет; интерфейс это прямо обозначает.

Подробности, границы проверки и установка: [docs/RELEASE-0.9.0.md](docs/RELEASE-0.9.0.md).

## Android: не удаляйте старую Деку

Если защищённая подпись не настроена, CI собирает **DeKa-preview-2.0.apk** (приложение «DeKa preview 2.0») с отдельным идентификатором `ru.volna.player.preview`. Это параллельная проверочная установка, не обновление поверх 0.8. Вход в VK выполняется заново; старая Дека и её данные остаются на месте.

Раскрытый signing key больше не извлекается из истории Git. Для постоянной подписи требуются GitHub Secrets `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEY_ALIAS`, `ANDROID_KEYSTORE_PASSWORD`. Preview использует временный ключ, который не публикуется и не сохраняется. Последующие preview-сборки могут потребовать переустановки только Preview.

## Структура

- `src/index.html` — прежний Windows-плеер и локальные файлы.
- `src/vk-bridge.js` — управление существующим плеером VK и его WebAudio-обработка.
- `src/library-engine.js` — тестируемый сборщик с явными состояниями завершения.
- `src/library-runtime.js` — адаптер DOM, кэш, навигация и поиск точного трека.
- `src/deck-engine.js` — две локальные аудиодеки и явно общий VK-поток.
- `src/set-core.js` — сеты VK Видео без DOM: ссылки, разбор треклиста по таймкодам, текущий трек, точка продолжения, позиции.
- `src/virtual-list.js` — длинные списки без тысяч DOM-элементов и сброса прокрутки.
- `src/mobile-overlay.js` — библиотека и горизонтальная DJ-панель.
- `src-tauri/` — нативная оболочка; порядок внедрения скриптов зафиксирован.
- `tests/` — модульные тесты и браузерные сценарии на локальной синтетической разметке.

Фоновый Android service из 0.7 сохраняется. Работа на физическом телефоне и с живой VK-сессией требует отдельной проверки; тестовая разметка не подтверждает все варианты интерфейса VK.

## Разработка

Для Windows нужны Node.js, Rust и C++ Build Tools. В корне проекта:

```sh
npm install
npm test
npm run dev
npm run build
```

`npm run build` создаёт `Deka.exe` и `Deka-setup.exe`. Существующие `update.cmd`/`update.ps1` оставлены для локальной разработки.

Браузерные проверки:

```sh
python -m pip install -r tests/requirements.txt
python -m playwright install chromium
python tests/browser.py
```

Тесты не заходят в VK и не требуют учётной записи. Результат и снимки экрана записываются в `test-output/`. GitHub Actions выполняет проверки до сборок Windows/Android. Проверочный релиз публикуется только из `main`, после успешных заданий.
